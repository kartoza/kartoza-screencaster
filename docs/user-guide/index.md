# User Guide

A feature-by-feature tour of Kartoza Screencaster. Each section is
designed to be readable in isolation, so jump straight to what you
need.

<div class="grid cards" markdown>

-   :material-view-quilt:{ .lg .middle } __Canvas editor__

    ---

    Compose your shot — screen, webcam, logos, GIFs, sounds — on a
    WYSIWYG canvas before you ever hit record.

    [:octicons-arrow-right-24: Canvas editor](canvas.md)

-   :material-record-circle:{ .lg .middle } __Recording__

    ---

    Start / pause / resume / stop. Multi-part recordings stitched
    seamlessly. Choice of compositor-aware capture pipelines.

    [:octicons-arrow-right-24: Recording](recording.md)

-   :material-webcam:{ .lg .middle } __Webcam overlay__

    ---

    Round, square or rectangle thumbnail with live preview.
    Independent of the screen capture.

    [:octicons-arrow-right-24: Webcam](webcam.md)

-   :material-image-multiple:{ .lg .middle } __Logos and GIFs__

    ---

    Multiple overlays. Loop limits on animated GIFs. Hold positions
    across recordings via presets.

    [:octicons-arrow-right-24: Logos and GIFs](overlays.md)

-   :material-volume-high:{ .lg .middle } __Audio__

    ---

    Microphone input, optional system audio, intro / outro stings,
    automatic denoise during post-processing.

    [:octicons-arrow-right-24: Audio](audio.md)

-   :material-history:{ .lg .middle } __History and playback__

    ---

    Local browser for every recording, with metadata, rename, replay
    and delete.

    [:octicons-arrow-right-24: History](history.md)

-   :material-youtube:{ .lg .middle } __YouTube upload__

    ---

    OAuth your account once. Upload from any recording with title,
    description, privacy, and category.

    [:octicons-arrow-right-24: YouTube](youtube.md)

</div>
