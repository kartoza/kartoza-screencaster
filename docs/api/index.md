# C++ API reference

This URL serves the **C++ API reference** generated by Doxygen when
the documentation site is published.

If you are seeing this page locally with `mkdocs serve` or
`nix run .#docs-serve`, the placeholder is in place because the
mkdocs-only build does not include the Doxygen output. To see the
real API browser locally, run:

```bash
nix run .#docs-full-build
```

Then open `site/api/index.html`. The deployed site at
[kartoza.github.io/kartoza-screencaster/api/](https://kartoza.github.io/kartoza-screencaster/api/)
always carries the live Doxygen output.
